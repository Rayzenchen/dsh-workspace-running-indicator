# 折叠工作区运行指示器（dsh-workspace-running-indicator）

DSH 插件：**侧边栏里某个工作区的会话列表收起时，只要这个工作区里还有会话在跑，就在工作区名称左边（文件夹图标的右侧）显示 DSH 自带的那个转圈圈图标。** 展开会话列表后图标自动消失，回到正在运行的会话名旁边显示。

![左侧是两个收起的工作区，其中在跑的那个在名称前显示转圈圈；右侧是展开后的同一个工作区，转圈圈回到正在运行的会话名旁边](docs/preview.svg)

## 它做什么

DSH 只在会话行上显示「运行中」的圆环。工作区一旦收起，会话行不再渲染，正在跑的任务就完全看不见了——这个插件把同一条信息提到工作区标题行上。

| 状态 | 你看到什么 |
|---|---|
| 工作区收起，其中有会话在跑 | 工作区名称左侧出现转圈圈 |
| 工作区收起，其中有子 agent 在跑（父会话空闲） | 同样出现，和会话行的判定一致 |
| 工作区收起，里面都很安静 | 什么都不显示 |
| 工作区展开 | 名称行的圆环消失，圆环只出现在正在运行的会话名旁边 |
| 会话跑完 | 圆环自动消失，不用刷新页面 |

## 和 DSH 原生图标一致

圆环不是照着画的，是把原生 `StateDot`「运行中」状态的标记、尺寸、描边与动画原样复刻：

| 项目 | 与原生一致之处 |
|---|---|
| 尺寸 | 14px（原生运行中圆环的尺寸），放在与会话行相同的 16×20 图标格里 |
| 颜色 | `--dsw-alias-label-tertiary`，与原生圆环同一个主题 token，深浅色主题自动跟随 |
| 动画 | 1.5s 匀速旋转 + 1.5s 弧形伸缩；`prefers-reduced-motion` 下静止 |
| 相位 | 插入时把动画时间轴归零，与页面上其他原生圆环同步转动 |
| 无障碍 | 圆环本身 `aria-hidden`（原生同款），旁边带视觉隐藏的「进行中」状态词，读屏会读出 |

状态词跟随 DSH 的 8 种内置语言（中文、英文、日文、西班牙文、法文、德文、俄文、葡萄牙文），用的是 DSH 自带 `status.running` 的同一套译文，切语言即时更新。

## 什么时候生效

- 只在「按工作区分组」和「工作区树」两种分组方式下生效——这两种才会有工作区行。
- 「扁平列表」和搜索视图没有工作区行，自然不显示。
- 侧边栏收成窄条（rail）时没有工作区行，也不显示。
- 「未分组」那一行不是真正的工作区，不标记。
- 与「工作区分类」这类只做 CSS 排序/隐藏的插件兼容：分类收起时工作区行仍挂在 DOM 里，圆环随之隐藏；分类展开即重新可见，不需要额外刷新。

## 安装

这是一个本地 bundle，二选一：

1. **界面安装**：设置 → **Plugins** → **Add plugin**，选择本目录；
2. **插件管理器安装**：把本目录路径作为 bundle 安装。

装上后在插件页能看到本插件，标题「折叠工作区运行指示器」。若侧边栏没有立刻出现圆环，刷新一次页面。

## 兼容性

- 适配 DSH **0.2.3-alpha.2**（当前运行版本）：圆环标记、主题 token、侧边栏槽位与行锚点都按该版本源码逐项核对。
- 从 DSH 0.2.3 起，会话状态表是独立嵌套服务 `uiSession.sessionStatus`，本插件在 Cordis `inject` 里同时声明父服务与该完整服务名；0.0.3 起已修正。
- **没有写 `engines.dsh`**：DSH 的预发布版（如 `0.2.4-alpha.1`）不满足任何 `^0.2.3-alpha.2` 形式的 SemVer 区间，写上会把整包判为不兼容而直接不加载。这个插件失效时只是图标不出现、侧边栏不受影响，所以宁可让它在新版本上先照常加载，再按需修。

## 已知边界

- 依赖侧边栏当前的 DOM 结构（`data-row-key="workspace:…"`、`aria-expanded`、`projectText`）与两个区域锚点（`[data-slot="sidebar.workspaces"]`、`[data-sidebar-list-area]`）。DSH 升级若把这套结构整体换掉，图标会不再出现；插件不会报错，且会在控制台留一条一次性提示（`the sidebar browsing region seam is gone`），便于定位。
- 归档过滤：插件排除的是「已归档的会话」。默认的隐藏归档过滤下这正好等于可见行；若把过滤切到「只看归档 / 显示归档」，收起时的圆环和展开后的可见行可能不完全一致。
- 收起且有人跑的工作区，其名称会比平常右移 22px（一格图标 16px + 行内间距 6px）。这是「把图标放到名称左侧」的必然代价；展开或没有任务时名称位置不变。

## 实现要点

- **事实来源**：`uiSession.sessionStatus`（会话行用的同一份状态快照）+ 会话列表的快照（状态未建立时的兜底、以及子 agent 目录）+ `workspaces.list`（工作区归属、归档集合）。不从 DOM 猜状态。
- **落位**：工作区行没有装饰插槽，所以按工作区浏览器自己的 DOM 落位，把图标插在名称单元前；React 重绘掉节点时会自动补回。
- **性能**：三份快照的订阅 + 一个 MutationObserver（只在侧边栏区域内变化时用 `requestAnimationFrame` 合并一次重排）；聊天流式输出不会触发重排。
- **生命周期**：样式、词典、订阅、观察器、插入的节点全部由 Cordis effect 持有，插件卸载时一并清除。
- 不导入任何 DSH Client 包，只使用主题 token 与原生 DOM。

## 版本历史

### 1.0.0

正式发布版：

- 统一版本号，补齐插件页展示信息（中英双语标题/描述 + 详情页配图）、MIT 许可、双语文档与发布校验脚本；
- 状态词补齐 DSH 全部 8 种内置语言；
- 侧边栏区域增加第二道锚点（`[data-sidebar-list-area]`）作为兜底，并在两道锚点都失效时给出一条一次性控制台提示；
- 其余功能与判定规则不变。

### 0.0.3（2026-11-23）

适配 DSH 0.2.3-alpha.2：修复插件页报错 `cannot get property "uiSession.sessionStatus" without inject`——会话状态表拆成了独立嵌套服务，读取它必须同时声明父服务与完整服务名；包清单的 `dsh.client.inject` 同步加上 `@deepseek-ai/dsh-client-ui-session-status`。

### 0.0.2

首个可长期使用的版本（当时 README 曾记为 1.0.0）：收起的工作区里只要有会话在跑（含只有子 agent 在跑）就在名称左侧显示原生圆环，展开即消失，实时跟随，读屏报「进行中」。

### 0.0.1

首个版本，功能同上。
